## What is this?

A Chrome Extension that auto-fills job application forms in 1 click.

When you are applying to 50 jobs daily, typing Name, Email, Phone, Experience, Location again and again wastes 2 hours. This tool fills it automatically.

## What it does

- Auto-detects Name, Email, Phone, Location, Experience fields on any job site
- Fills your saved profile in 1 click
- Works on LinkedIn, Naukri, Indeed, Shine, Michael Page company career pages
- Saves multiple profiles - IT Manager, Developer, etc.
- One-click Resume / CV upload helper
- Saves your data locally in browser - No server, 100% Private

## Tech Stack

- JavaScript
- Chrome Extension Manifest V3
- HTML / CSS
- Chrome Storage API

## How to Install

1. Download / Clone this repo
2. Go to `chrome://extensions` in Chrome
3. Turn ON `Developer Mode`
4. Click `Load Unpacked` and select this folder
5. Pin the extension in toolbar

## How to Use

1. Click extension icon > Fill your profile once (Target Job Title, Target City, Name, Email, Total Experience (Years), Phone, Experience, Current CTC (₹), Expected CTC (₹), Notice Period)
2. Open any Job Application page
3. Click `Auto-Fill` - Form fills in 2 seconds
4. Check details and click Submit

## Why I Built This

I was applying to jobs and filling same 15 fields 20 times a day. Built this to save time and apply faster without mistakes.

## Privacy

Your data stays in YOUR browser only. No data is sent to any server.
